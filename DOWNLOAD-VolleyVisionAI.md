# VolleyVision AI 0.3 — архив для тестирования

Файл VolleyVisionAI-v0.3.0.zip содержит исходники, собранный интерфейс и скрипты установки Windows.
Видео, веса, секреты и установленный Python в архив не включены. Зависимости и веса устанавливаются setup-скриптами.

1. Скачайте ZIP через кнопку Download raw file в GitHub и распакуйте его.
2. В папке VolleyVisionAI выполните setup.ps1 -WithAI, затем start.ps1.
3. Перед обновлением сохраните прежний data.

Версия 0.3 — пилот детекции, не полный автоматический разбор волейбола. Полные ограничения — README.md внутри архива.
